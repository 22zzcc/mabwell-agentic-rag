# BD 项目评估与交易结构分析（投资/金融分析）

## 1. 管线估值方法

### 1.1 风险调整净现值（rNPV）
对在研管线采用风险调整净现值法估值：将未来各期现金流按临床成功概率加权后折现。Ⅲ期项目的成功率通常取 60%~70%，Ⅰ期取 10%~20%。

### 1.2 折现率
生物医药项目风险高，折现率一般取 12%~15%；早期项目（临床前/Ⅰ期）取上限，后期项目（Ⅲ期/已上市）取下限。

## 2. 交易结构设计

### 2.1 首付款与里程碑
License-out 交易常见结构为「首付款 + 研发/注册/销售里程碑 + 销售分成」。首付款比例越高，买方承担风险越大，卖方当下现金流越稳。

### 2.2 销售分成（Royalty）
销售分成率通常按净销售额的一定比例计提，抗肿瘤创新药一般在 10%~20% 区间；生物类似药因竞争激烈，分成率通常更低。

## 3. 财务回报测算

### 3.1 内部收益率（IRR）
以某 ADC 项目为例：首付款 3000 万美元、里程碑合计 3 亿美元、峰值销售 8 亿美元、分成率 12%，测算交易 IRR 约为 18%。

### 3.2 敏感性分析
IRR 对峰值销售与上市时间最敏感：峰值销售每下降 20%，IRR 约下降 3~4 个百分点；上市每推迟一年，IRR 约下降 1.5 个百分点。
