# 抗体纯度偏低的根因分析

## 1. 聚集体导致纯度偏低

### 1.1 原因
蛋白聚集是导致 SEC-HPLC 单体纯度偏低的常见原因。pH 偏离等电点、温度波动、搅拌产生的剪切力、冻融循环等因素都可能诱发抗体聚集，使高分子量聚集体峰升高、单体主峰下降。

### 1.2 应对
优化制剂缓冲液配方与 pH，控制搅拌转速，规范冻融流程，必要时加入表面活性剂。

## 2. 电荷异质性导致主峰下降

### 2.1 原因
脱酰胺、氧化、糖基化末端唾液酸化等翻译后修饰会改变抗体电荷，使酸性峰或碱性峰比例升高，主峰纯度相应下降。细胞培养阶段的培养时间过长、培养基成分变化会加剧此类修饰。

### 2.2 应对
控制细胞培养工艺参数（培养时间、溶氧、补料策略），优化离子交换层析的分离条件。

## 3. 片段与降解产物

### 3.1 原因
铰链区还原断裂或收获液中蛋白酶降解会生成 Fab、Fc 等抗体片段，SEC 图谱上表现为低分子量组分，拉低单体纯度。

### 3.2 应对
优化收获液处理温度与时间，及时添加蛋白酶抑制剂，强化 Protein A 亲和层析后的精纯步骤。

## 4. 工艺相关杂质残留

### 4.1 原因
内毒素残留、宿主细胞蛋白（HCP）残留、Protein A 配基脱落、残留 DNA 等工艺相关杂质，虽不一定直接改变 SEC 主峰，但会触发放行标准其它检验项不合格，同样属于「纯度/质量」问题。

### 4.2 应对
强化层析步骤与病毒灭活/去除工艺，对 HCP、残留 DNA、内毒素建立中间过程控制（IPC）。

## 5. 分析方法本身的影响

### 5.1 原因
SEC 柱效下降、流动相条件不当、样品前处理（如稀释、过滤）引起聚集等分析方法因素，也可能造成「测得的纯度偏低」的假象，需与真实工艺偏差区分。

### 5.2 应对
定期进行系统适用性试验，与参比品对照，异常时先复核分析方法再下工艺结论。
