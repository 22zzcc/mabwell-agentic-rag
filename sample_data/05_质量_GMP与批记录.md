# GMP 质量标准与批检验记录

## 1. 质量标准的建立

### 1.1 放行标准
药品放行标准是判断成品是否可上市销售的质量依据。抗体药物成品的放行标准通常包括：鉴别、纯度（SEC-HPLC 单体纯度不低于 95%）、聚集体、电荷异质性、内毒素（不高于 0.5 EU/mg）、无菌与可见异物等检验项目。

### 1.2 标准品与对照品
检验用标准品需经充分表征并建立二级对照品管理体系，确保检验结果的溯源性。

## 2. 批检验记录

### 2.1 批记录要求
每批产品生产与检验过程须形成完整的批记录，做到可追溯、可复核。批检验记录应记录检验方法、仪器编号、原始数据与检验结论。

### 2.2 数据完整性
电子数据应符合 ALCOA+ 原则（可归属、清晰、同步、原始、准确），关键数据需审计追踪，防止数据篡改。

## 3. 偏差与变更管理

### 3.1 偏差处理流程
生产检验过程中发生的任何偏离既定规程的事件均需按偏差管理流程处理，包括偏差的发现、记录、影响评估、根本原因分析与纠正预防措施（CAPA）。

### 3.2 变更控制
对工艺、设备、物料、检验方法等变更，须经变更控制评估其对产品质量的潜在影响，必要时开展稳定性研究与工艺验证。
